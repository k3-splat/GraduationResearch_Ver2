# 卒業研究：双方向予測符号化のスパイキングニューラルネットワークへの実装

本リポジトリは、卒業研究に関するソースコードおよび関連資料をまとめたものです。

## 概要 (Overview)
AI（人工知能）の省電力化を目指し、**人間の脳の仕組みに近いネットワークを用いた新しい学習アルゴリズム**を提案・実装しました。
画像から数字を「認識」する機能と、その数字の画像を「生成」する機能の双方向を、省電力なモデル上で実現することに挑戦しています。

## 1. 研究の背景と課題 (Background)
現在、大規模言語モデル（LLM）などに代表される深層学習技術は非常に高い性能を持っていますが、同時に**膨大な電力と計算資源を消費する**という大きな課題を抱えています。
一方で、人間の脳はわずかなエネルギーで高度な情報処理を行っています。そこで、脳の神経細胞の動きをコンピュータ上で模倣した「**スパイキングニューラルネットワーク（SNN）**」というモデルが注目されています。SNNは必要な時だけ「スパイク」と呼ばれる短い信号（0と1のデジタル値）で通信するため、**消費エネルギーを劇的に抑えられる**可能性があります。

## 2. アプローチと提案手法 (Approach)
本研究では、この省エネなSNNをさらに賢く学習させるための新しい学習ルール「**Diff-bPC (Difference Bi-Predictive Coding)**」を独自に構築し、Pythonを用いて実装しました。

この手法の特徴は、脳が行っているとされる「予測」の仕組みを取り入れたことです。画像を見て「これは何という数字か」を当てる（識別タスク）だけでなく、「この数字ならこんな形だろう」と想像する（生成タスク）という**双方向のやり取り**を、省電力なSNN上で同時に行えるように設計しました。

## 3. 結果・成果 (Results)
手書き数字の画像データ（MNIST）を用いた評価実験を行いました。
- **認識精度**：93.84%の分類精度を達成しました。
- **通信コストの削減**：従来型の（省エネではない）モデルと比較して、AI内部の層間で行われる**データ通信量を大幅に削減**することに成功しました。

精度や生成画像の鮮明さにおいては既存の手法にまだ及ばない部分（情報の欠落によるトレードオフ）があるものの、次世代の「省電力で効率的なAI」に向けた新しい計算アルゴリズムの基礎を示すことができました。
